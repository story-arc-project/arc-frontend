# FRT-223 반복 기록 행 맥락

반복 기록의 9개 컬럼 유형에서 접근 가능한 이름에 현재 표시 행 번호와 컬럼명을 포함한다. `1번째 기록 프로젝트명`, `1번째 기록 기간 시작/종료/현재` 형식을 사용한다. 추가/삭제/부모의 순서 변경 후 번호는 현재 순서에서 다시 파생하고 저장 값과 row id는 보존한다. 빈 표시 행도 1번째 기록이다.

기술 선택은 요청에 따라 자율 결정: RowEditor에서 공통 이름을 만들어 전달한다. aria-describedby만 붙이는 대안은 컨트롤 이름만 조회할 때 행을 구분하지 못하므로 채택하지 않는다. 체크리스트 옵션 및 역할 칩 분기에도 컬럼·행 맥락과 옵션명을 함께 전달한다. 행 삭제 버튼에도 번호를 붙인다. 행 추가 기능·정렬 UI를 새로 만들지 않는다. 행 부가항목/결과물 편집은 기존 구조를 유지하며 이번 원본 범위는 9개 컬럼이다.
