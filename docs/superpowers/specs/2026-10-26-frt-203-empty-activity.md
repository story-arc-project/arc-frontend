# FRT-203 빈 활동 표시 기준

목적: 진행 중 또는 날짜만 있는 활동을 미리보기·PDF/DOCX 문서에서 숨긴다.
활동명, 기관, 역할, 활동내용, 성과 중 공백이 아닌 내용 하나라도 있으면 표시한다.
표시=false 및 표시순위의 기존 계약을 유지하며 원본 입력은 보존한다.
일반 isEmptySection 변경은 다른 섹션에 영향을 주고 편집 입력 강제는 범위를 넘으므로 사용하지 않는다.
활동 전용 공유 필터를 두 소비처에서 사용한다. 사용자 위임 범위의 구현 선택이다.
저장·마이그레이션·입력 정책은 변경하지 않는다. 최신 UI 승인 전 머지하지 않는다.
