# FRT-137 분석 출력 경계 방어

목적: 잘못된 AI 출력에서도 분석 상세가 과장된 수치나 부정된 강점을 보여주지 않고, 기존 상세가 안전하게 열린다.

승인 범위: 단일 이슈의 명시된 5규칙과 일반 구현 선택은 사용자 실행 위임에 포함된다. 최신 UI에 대한 별도 승인은 머지 전에 필요하다. 연결된 Notion 태스크 없음(Linear 단독).

## 접근과 경계

기존 방어 매퍼에서 유효성 판정 후 UI는 숨김 상태를 렌더한다. UI에서만 원시값을 검사하면 asNumber 기본값 때문에 누락과 실제 0을 구분하지 못한다. 수치를 재계산하거나 강점을 추론하는 대안은 원본 의미를 바꾸므로 채택하지 않는다.

- coverage 분모가 없거나 양수가 아니거나 관련 수보다 작으면 fraction/percent/progressbar를 숨긴다. 비정상 숫자도 숨긴다. 유효한 API 비율은 재계산하지 않는다. 키워드·등급별 개수는 유지한다.
- has_genuine_strengths 명시 false는 긍정 강점 필드를 비운다. no_strength_reason 안내는 보존한다. 플래그가 없는 구 레코드 호환을 유지한다.
- 종합 학교/학과 숨김과 강점→보완점 고정 순서는 현행 구현을 유지하고 회귀로 증명한다.
- 레쥬메 meta.format은 상세 렌더 분기에 사용하지 않는 현행 경로를 검증한다. 형식만 이유로 새 기본 통계를 만들지 않는다.
- backend/API 정책·권한·결제·다른 PR 기능 변경 제외. Mock/DOM 검증은 실제 API·배포·실물기기 증거와 구분한다.

## 검증

잘못된 원시 응답으로 API 매퍼와 실제 상세 화면을 검증한다. Vitest RED→GREEN, Node20 lint/typecheck/unit/build, 데스크톱1440/모바일390 Playwright 및 원격 미리보기, 독립 리뷰 후 Ready PR(base dev)과 최신 head Codex 리뷰 요청을 남긴다.
