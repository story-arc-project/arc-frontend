# FRT-275 표 셀 접근 이름

셀 입력의 접근 이름은 블록명, 현재 1-based 행 번호, 1-based 열 번호와 열명을 포함한다. 예: `성과 지표 1행 2열 결과`. 같은 열명이 반복되어도 열 번호로 구분한다. 편집 블록은 useId 기반 라벨 연결을 가진 group으로 묶어 같은 제목의 블록도 DOM 연결이 충돌하지 않는다.

행 추가·삭제 후 현재 위치에서 번호를 다시 파생한다. 값, 저장 shape, 읽기전용 렌더링, 레이아웃 및 기존 행 삭제 동작은 유지한다. 신규 행/열 이름과 키보드 편집을 회귀 검증한다. 실제 스크린리더 음성·실서버·배포 검증은 별도다.
