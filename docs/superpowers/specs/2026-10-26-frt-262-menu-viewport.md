# FRT-262 메뉴 경계 설계

사용자 위임 범위: ExperienceCard 메뉴 geometry만 수정. 작은 높이·좁은 폭에서도 모든 항목에 도달한다. 기존 포털, 수평 보정, 바깥 클릭, Escape, 라이브러리 변경 콜백을 보존한다. 데이터/목록/멤버십 훅은 수정하지 않는다. UI 승인 전 머지 금지.

원인: 메뉴와 서브메뉴는 fixed portal이나 top을 viewport 높이에 보정하지 않는다. 전역 scroll 닫기는 새 내부스크롤을 방해한다.

접근 비교: 고정 예상 높이는 항목 수·폰트 변화에 취약하다. 새 popover 라이브러리는 범위와 동작 변화를 늘린다. 실제 DOM 크기를 layout effect로 측정하여 8px 여백 안에 clamp하고 max-height 및 overflow-y를 적용하는 최소 접근을 채택한다(일반 구현 선택 자율 승인).

아래 공간이 부족하면 위로 열고 clamp한다. 서브메뉴는 기존 좌우 선호를 유지하며 수직 보정한다. resize에서 재배치한다. 외부 scroll은 닫고 내부 scroll은 유지한다. 안전 API stub에서만 클릭 검증한다. 운영 데이터 수정·운영 배포는 하지 않는다.
