# FRT-334: 자소서 표시의 최소 Markdown 방어

사용자 지시로 범위와 실행을 확정했다. CoverLetterPreview에서 기존·신규 본문의 명확한 Markdown 기호만 표시에서 제거한다. API/저장 원문, 편집값, 원문 비교, 글자수/제한, grounding 판정, feature flag는 보존한다. ReactMarkdown 추가 금지.

## 접근
전역 기호 삭제는 정상 값 손실이 생기므로 배제한다. 렌더러 추가는 범위 밖이다. 문자열을 보수적으로 판정하고 제거 위치를 구한 뒤 원문 기반 grounding segments에 투영한다. 강조 경계가 하이라이트 경계와 달라도 기호가 남거나 경고가 사라지지 않아야 한다.

## 판정
- 유효한 쌍의 **강조** 및 __강조__만 제거. 비어 있거나 공백 경계/미완성/escape/단어 내부 underscore/모호한 연산은 보존한다. 명확한 시작 경계가 있으면 닫는 __ 뒤 한글 조사는 허용한다(__협업__으로). ASCII 식별자 접미사(__init__method)는 보존한다. 단일 별표/underscore는 최소 집합 밖이라 보존한다.
- 줄 시작 0~3칸 뒤 1~6개 #와 공백+내용은 헤더, 선택적 닫는 #는 명확한 헤더 문법이면 제거한다. #태그, C#, inline # 보존.
- 불릿(-,+,*) 또는 순서 목록(1.,2. 또는 1),2))은 같은 들여쓰기·같은 마커 계열의 연속 2줄 이상에서만 제거한다. 숫자는 연속 증가하는 항목임을 확인한다. 단독 숫자/문장부호/음수/날짜/소수/단독 대시 보존. 빈줄은 바꾸지 않는다.
- 수평선, 코드, 링크, HTML, 기타 Markdown 문법은 범위 밖. 정상 문자 그대로 React text로 표시한다.

## 사용자 승인 보수적 문단 보존 (Task 1c)
`[`와 백틱이 함께 있는 문단은 최종 제거 위치를 무효화하여 원문 그대로 보존한다. LF/CRLF의 빈 줄(공백·탭만 있는 줄 포함)이 문단 경계이며 단일 줄바꿈은 같은 문단이다. 해당 문단의 정상 강조·헤더·목록 기호도 남기는 오탐 보존을 사용자가 승인했다. 분리된 다른 문단에는 기존 최소 정리를 적용한다. 이는 완전한 Markdown 정리가 아닌 원문 보존 우선 절충이며, 구문 스캐너·원문 grounding·글자수·저장값은 바꾸지 않는다.

## 상태·검증
기존 empty/multiple/flagged/edited 상태를 유지한다. 원문과 strip 결과가 다르더라도 원문 글자 수를 유지한다. 원문 grounding 부분 매칭 후 표시 투영, 본문을 편집했을 때 highlight 해제를 유지한다. 유틸 TDD, 컴포넌트 회귀와 Storybook play, desktop/mobile Storybook 캡처를 준비한다. 노출 flag를 켜지 않는다.
